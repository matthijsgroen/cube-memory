# Cube Memory

A Set of games to train blindfolded 3x3 cube solving

- Edge memory

  - Practice mode: Can you name the proper letter location for the shown edge?
    - Show response time
    - Keep track of response times over time
  - Chain mode:
    - quickly assign letters to a chain
    - get results at the end in amount correct and average response time

- Corner memory

  - Practice mode: Can you name the proper letter location for the shown edge?
    - Show response time
    - Keep track of response times over time
  - Chain mode:
    - quickly assign letters to a chain
    - get results at the end in amount correct and average response time

- Chain memory
  - How well can you remember a chain of characters?

## Implementation Goals:

- Should be playable on mobile
- Should look really nice
